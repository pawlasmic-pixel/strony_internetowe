Pobierz dla 1.21.11
  1. Zainstaluj Fabric Loader dla wersji 1.21.11.
  2. Pobierz Fabric API dla 1.21.11 (Modrinth), bez niego mod nie wystartuje.
  3. Wrzuć oba pliki .jar do %appdata%\.minecraft\mods.
  4. Uruchom grę profilem Fabric i wciśnij prawy Alt, żeby otworzyć ClickGUI.
